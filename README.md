# 소리랑 놀이터

놀이터의 소리와 움직임을 목소리와 음악으로 표현하는 초등 음악 수업용 웹앱입니다. 학생 로그인이나 Firebase 설정 없이 사용할 수 있습니다.

## 활동 순서

1. **소리 찾기**: 새로 그린 놀이터 그림에서 미끄럼틀·소리 전달 놀이기구·회전 놀이기구·시소·오르기 놀이기구를 직접 누릅니다. 움직임을 목소리로 흉내 내고 소리말을 씁니다. 원하면 최대 6초간 목소리를 녹음합니다. **직접 그리기**에서 소리의 움직임을 선과 점으로 그리고, **그린 소리 듣기**로 들어 본 다음 **이 그림으로 담기**를 누릅니다. 한 선 취소·모두 지우기·예시 모양을 사용할 수 있습니다. 빠르기와 소리 크기도 바꿀 수 있습니다. ‘악기·음정’에서 피아노·전자음·마라카스·실로폰·종소리·북·바이올린·탬버린 중 하나를 선택합니다.
2. **악보 만들기**: 놀이기구를 선택하고 네 칸에 소리를 담습니다. ‘소리 찾기’에서 직접 그린 움직임이 새 장면에 그대로 복사됩니다. 손가락이나 펜으로 소리의 높낮이를 그리고, **크게 그리기**로 넓은 창에서 편집할 수도 있습니다. 장면의 그림을 고쳐도 다른 장면이나 소리 찾기의 원본은 바뀌지 않습니다. 위쪽은 높은 소리, 아래쪽은 낮은 소리입니다. 같은 소리를 반복하거나 빈칸을 두어 쉴 수 있습니다. 녹음한 목소리와 그림선 음악 중에서 장면마다 선택합니다. 그림 악보 위의 ‘악기·음정’ 버튼으로 같은 놀이기구라도 장면마다 다른 악기와 음을 정할 수 있습니다.
3. **내 작품 발표**: 왼쪽부터 한 장면에 4박씩 연주합니다. 전자칠판에서는 ‘크게 발표하기’를 이용합니다. ‘그림+연주 동영상’으로 그림 악보와 연주를 함께 저장합니다. 그림 악보(PNG), 연주(WAV), 다시 편집할 작품 파일(JSON)도 저장할 수 있습니다.

### 악기와 음정

- 도·레·미·파·솔·라·시와 낮은음·보통음·높은음을 선택합니다. 음 이름을 누르면 선택한 악기의 한 음을 들을 수 있습니다.
- ‘그림선 따라’는 고른 음을 가운데 기준음으로 삼아 그림선의 높낮이를 도레미 음계로 연주합니다. ‘한 음으로’는 그림과 상관없이 고른 음을 유지하고, 선의 위치와 길이를 소리의 시작과 길이로 사용합니다.
- 마라카스·북·탬버린은 일정한 음정이 없는 타악기이므로 음정 선택을 비활성화합니다. 그림선과 빠르기에 따라 리듬을 만들고 소리 크기를 바꿉니다.
- 악기 소리는 브라우저에서 합성합니다. 실제 악기의 녹음 음원을 내려받지 않으며 외부 음원 요청이나 설치가 필요 없습니다.
- 소리 찾기에서 고른 악기는 새로 악보에 담는 장면의 기본값입니다. 이미 담은 장면의 악기를 바꾸려면 그 장면을 선택하고 ‘악기·음정’을 누릅니다. 악보에서 악기를 적용하면 해당 장면을 음악 모드로 연주합니다.

- 바이올린은 활로 켜는 소리를 부드러운 시작과 길게 이어지는 울림으로 표현합니다. 음정·음높이와 그림선 연주를 모두 선택할 수 있습니다. 탬버린은 금속 방울의 짤랑거림과 두드리는 리듬으로 표현합니다. 두 악기도 WAV와 동영상에 똑같이 반영됩니다.

### 개인 활동

- 학생이 각자 태블릿 한 대로 활동합니다. 화면 위쪽의 ‘내 이름’을 적고 자기 소리말·녹음·그림 악보·소감을 만듭니다. 학생 로그인은 필요 없습니다.
- 같은 주소로 들어가도 작품은 기기와 브라우저마다 독립적으로 저장되어 친구 작품과 섞이지 않습니다. 실시간 공동 편집이나 교사용 수합 기능은 없습니다.
- 작품 제목과 내 이름은 자유롭게 입력합니다. 악보 그림에는 이름이 표시되고, PNG·WAV·MP4/WebM·JSON 파일 이름 앞에도 학생 이름이 붙어 수합하기 편리합니다.
- 기기를 돌려 쓸 때에는 먼저 각자의 작품 파일(JSON)을 저장한 다음 새 작품을 시작합니다. 같은 기기에서 이름만 바꾼다고 이전 작품이 자동 분리되는 것은 아닙니다.
- 40분 수업 예시: 장면 살피기와 목소리 탐색 10분 → 나만의 소리말과 그림 악보 만들기 20분 → 발표와 소감 나누기 10분.
- 음악을 듣기 전에 학생이 직접 목소리를 표현하고 친구의 소리에 귀 기울이도록 안내할 수 있습니다.

### 그림과 연주를 동영상으로 저장하기

1. ‘내 작품 발표’에서 **그림+연주 동영상**을 누릅니다.
2. 네 장면의 그림 악보와 소리말, 이름과 제목이 1280×720 가로 영상에 담깁니다. 재생 중인 장면과 그림선 위의 위치가 함께 표시됩니다. 장면에서 음악 모드를 골랐다면 선택한 악기·음정으로, 목소리 모드를 골랐다면 녹음한 목소리로 저장합니다. 빈 장면은 쉼으로 남습니다.
3. 연주 길이만큼 기다립니다(빠르기에 따라 약 8~19초). 만드는 중에는 현재 화면을 열어 둡니다. 다른 탭이나 앱으로 이동하면 취소되며, 작품은 유지됩니다.
4. 완성 영상을 재생해 본 뒤 **동영상 내려받기**를 누릅니다. 브라우저가 지원하는 MP4 또는 WebM 형식으로 저장합니다. 파일 확장자는 실제 저장 형식을 따릅니다. Chrome에서 MP4에 영상·음성이 모두 포함된 파일의 다운로드를 확인했습니다. 실제 학생 태블릿에서는 기기별 지원 형식을 한 번 확인합니다.
5. 동영상 만들기는 앱의 그림과 연주만 담으며, 화면 공유·카메라·추가 마이크 권한을 요청하지 않습니다. 녹음한 목소리를 쓰려는 경우에는 앞 단계에서 녹음해야 합니다. 동영상 기능이 없는 브라우저에서는 PNG와 WAV를 따로 저장할 수 있습니다.

## GitHub + Vercel로 배포하기

1. ZIP을 풀고 **dist 폴더, vercel.json, package.json 등이 바로 보이는 위치의 파일 전체**를 GitHub 새 저장소에 올립니다. 바깥 폴더를 한 번 더 감싸 올리지 않습니다.
2. Vercel에서 Add New → Project → 해당 저장소를 선택합니다.
3. Framework Preset은 **Other**, Root Directory는 기본값을 사용합니다. Output Directory는 **dist**입니다. Build Command와 Install Command는 비웁니다. 포함된 vercel.json이 이 설정을 적용합니다.
4. Deploy를 누르고 발급된 HTTPS 주소를 학생에게 공유합니다. 별도의 환경변수나 데이터베이스는 필요 없습니다.
5. 코드 수정 후 GitHub에 반영하면 연결된 Vercel 프로젝트가 다시 배포됩니다.

Vercel 이외의 정적 호스팅에서는 `dist` 안의 파일을 올립니다. `index.html`을 파일 탐색기에서 직접 더블클릭하면 JavaScript 모듈과 녹음 기능이 제한될 수 있으므로 HTTPS로 배포한 주소를 사용합니다.

## 녹음과 저장

- 녹음할 때만 마이크 권한을 요청합니다. 거부해도 음악 만들기와 직접 목소리 표현 활동을 계속할 수 있습니다.
- Chrome 또는 Samsung Internet의 최신 버전을 권장합니다. 학교 관리 태블릿은 마이크 권한이 제한될 수 있습니다.
- 소리말·그림 악보는 localStorage, 녹음은 IndexedDB에 보관합니다. 서버로 학생 작품이나 목소리를 전송하지 않습니다. 별도 분석 도구나 외부 폰트·음원 요청도 없습니다.
- 기기를 바꾸거나 브라우저 기록/사이트 데이터를 지우기 전에는 ‘작품 파일 저장’을 이용합니다. JSON 파일에 악보와 녹음이 함께 담깁니다. 같은 앱의 ‘작품 파일 열기’에서 복원할 수 있습니다.
- 저장한 JSON은 다시 편집하는 파일입니다. PNG는 악보 그림, WAV는 연주 소리, MP4/WebM은 그림과 소리를 함께 담은 동영상입니다.
- 한 장면은 4박입니다. 녹음이 장면보다 길면 그 장면 길이까지만 재생하며 목소리 높이를 바꾸지 않습니다. 긴 녹음을 모두 듣고 싶으면 전체 빠르기를 낮춥니다. 녹음 원본은 ‘내 목소리 듣기’ 옆 저장 버튼에서 따로 저장합니다.
- 음악 재생은 브라우저의 Web Audio 기능을 사용합니다. 태블릿의 미디어 음량을 확인합니다. 녹음 중에는 다른 소리가 섞이지 않도록 음악 재생을 잠시 막습니다.

## 파일 구성

- `dist/index.html`: 앱 화면 진입점
- `dist/style.css`: 반응형 화면
- `dist/cute.css`: 크림·분홍·보라·민트색의 둥근 음악 놀이터 디자인
- `dist/icons.js`: 동일한 화풍의 둥근 선과 색을 사용한 음악·악기 아이콘
- `dist/video.js`: 그림 악보의 움직임과 연주를 합친 동영상 생성·형식 선택
- `dist/app.js`: 활동·녹음·그림 악보·파일 저장
- `dist/drawing.js`: 손가락·펜·마우스의 선과 점 입력, 취소·초기화, 작은 악보와 넓은 그리기 창의 공통 처리
- `dist/art.js`: 음악책 속 다섯 놀이기구·그림 터치 영역·같은 그림을 사용하는 미리보기
- `dist/assets/playground.png`: 음악책의 놀이기구 구성을 참고해 새로 그린 아기자기한 놀이터 그림
- `dist/audio.js`: 여덟 악기의 실시간/오프라인 음악 합성 및 WAV 생성
- `dist/music.js`: 악기·음정·옥타브 설정과 그림 악보의 음표/리듬 계산
- `dist/storage.js`: 기기 저장·작품 검증·녹음 관리
- `vercel.json`: Vercel 정적 배포 설정
- `tests/core.test.mjs`: 작품 복원, 녹음 파일 형식, WAV 출력 검사

외부 패키지 설치 없이 실행합니다. Node.js가 있다면 `npm run check`와 `npm test`로 검사할 수 있습니다. 교과서의 그림이나 지면 자체는 앱에 포함하지 않았으며, 새로 제작한 놀이터 일러스트를 사용합니다.
